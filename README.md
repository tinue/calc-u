# Calc-U: document archive

This branch holds documents only, no code. It keeps the requirements,
plans, designs, decisions and reviews of the phases that brought
Calc-U-59 and Calc-U-1600 into one repository: the briefing, the
ADRs, the contracts, the feature specs and designs with their QA reports,
the migration plan, the inventories, the reviews and the prompts.

- The code, the formal specifications and the operational documents are
  on `main`.
- The full snapshot, code and documents together, is the tag
  `history-phases-0-6`.
- Every document keeps the path it had on `main`, so the links between
  them still work. Links to code or to documents that stayed on `main`
  resolve at that tag.

Nothing here is edited. A document that becomes superfluous on `main`
may be added here later (and deleted on `main`); code never comes here.
These documents record how things were decided; they are not an argument
for or against how things are today.
