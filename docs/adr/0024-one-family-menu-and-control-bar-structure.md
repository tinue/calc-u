# One menu and control-bar structure for the family

Status: accepted (2026-11-09)

Every product uses the same menus with the same items wherever it has the
function: presets in File, Reset and Cold boot in Machine, Settings where
the platform expects it, Help last. Below the calculator, a control bar
holds the machine's hardware: the model first, then one picker per module
slot and per media place. Items a product lacks simply don't appear; on
iOS the same items appear without a menu bar. Learning one product thus
teaches the others (Briefing §1.5). Today Calc-U-59 has a control bar with
buttons and a small File menu, Calc-U-1600 four menus and a richer
control bar.
