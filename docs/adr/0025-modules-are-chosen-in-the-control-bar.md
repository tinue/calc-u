# Modules are chosen in the control bar

Status: accepted (2026-11-09)

In every product, a module is chosen with a picker for its module slot in
the control bar, listing the templates and the user's instances, and it
plugs in immediately. The TI-59 gets one picker for its 8-pin slot with
its 14 Solid State ROM modules; its Settings entry for the module goes,
because settings no longer hold hardware (ADR 0021). This is Calc-U-1600's
way (C4 in the divergence matrix).
