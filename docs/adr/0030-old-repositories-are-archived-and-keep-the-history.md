# The old repositories are archived and keep the history

Status: accepted (2026-11-09)

After the first release of a product from tinue/calc-u, its old repository
(tinue/Calc-U-59, tinue/Calc-U-1600) gets a README that points to
tinue/calc-u and is archived (read-only) on GitHub. Its full history, its
past releases and their assets stay there and stay downloadable, which is
how the history of both repositories is preserved (Briefing §3, §6). The
source repository starts from imported trees, not from the old histories.
