# User-visible behaviour changes

Briefing §1.1 says no user-visible feature breaks. The decisions of
phases 3 and 4 made exceptions and changes; this file lists them in one
place, per product, each with its source. It is the seed of each
product's release notes for its first release from this repository, and
the list of places where the acceptance criteria of phase 4b do **not**
describe today's behaviour (`docs/Process.md`, phase 4b).

A new decision that changes what a user sees adds a row here in the same
step. Label and menu renames are not repeated here; they are in
`docs/glossary-mapping.md` ("Visible renames").

## Calc-U-59 (against 2.3.0)

| # | Change | Source |
|---|---|---|
| 59-1 | Files written for 2.3.0 are refused with a hint to upgrade them: presets (`.ti59`, `.ti58`, `.ti58c`) and ASM overlays. Magnetic cards (`.u59`, every layout) and `ti58c.mem` are ignored: the product no longer reads, lists or changes them, and the user converts them by hand. The new files have new names and formats: magnetic cards are `.magnetcard.yaml` (magnetic card format 3, with the name inside), the constant memory file is `ti58c.memory.yaml` (constant memory format 1). A one-time exception for this release. The ASM overlay format becomes version 2.0: the first line is `Calc-U-59 ASM 2.0`, a `;` starts a comment after `HEX:`, and an instruction above 1FFF, a run of fewer than four digits, or a word after `HEX:` refuses the file (today: cut to 13 bits, passed over). A cold boot or a new machine removes a loaded overlay (today it outlives a model switch and a preset). An `.asm` file can be dropped and opened like any file (today: only chosen in the debug panel). | ADR 0037; `contracts/media.md`, MD-2, Q-4; C59-4 AC-14, AC-15, AC-19, AC-26 (user, batch 8 gate); `docs/formats/README.md` |
| 59-2 | Settings start at their defaults; the platform stores are not converted. | `contracts/settings.md`, ST-1 |
| 59-3 | The preset format is new (YAML-shaped, key IDs instead of matrix codes, `format-version: 2`); a preset with any error is refused whole. | ADR 0017, 0018; `contracts/presets.md` |
| 59-4 | A preset always builds its machine from a cold boot. It no longer adds to the running calculator, and it no longer keeps the module or printer it does not name. A preset names its model: one written for 2.3.0 without `MODEL:` loaded into the model that was running, and its upgraded file names the model of its extension, so `diag.ti58` now switches to a TI-58. | ADR 0016; `contracts/presets.md`, PR-2; C59-2 AC-10 |
| 59-5 | A preset's steps run at full speed unless a speed step asks for regular speed; user keys are dropped while it runs. While a preset or another operation runs at full speed for more than half a second, "Loading…" is shown. | `contracts/presets.md`, PR-4; `contracts/typing.md`, T-4; LIB-14 AC-15 |
| 59-6 | Magnetic cards the product makes live in the save folder, also in the Web frontend, where they are now kept between visits; a card gets a name inside its file; `.bin` is no longer a card. A card file opened from elsewhere is still used and written back where it lies. A write rewrites the card file but replaces only the side written; the name, description and cue card stay (`docs/formats/media.md` §1.4). | ADR 0019 as amended; `contracts/media.md`, MD-2, MD-5; C59-7, LIB-13 (user, batch 7 gate) |
| 59-7 | *Withdrawn 2026-11-13:* a card file a preset names is written in place unless it is a template, as today (ADR 0019 as amended 2026-11-13). | user, 2026-11-13 |
| 59-8 | On the web, magnetic cards persist across page loads. When the product is open twice in one browser, only the first copy keeps what is saved; the second says so. | `contracts/settings.md`, ST-3; `features/LIB-15-web-frontend-shell/spec.md` |
| 59-9 | The Solid State ROM module is chosen in the control bar, not in the settings, and the choice is not remembered across starts; a startup preset sets it. The picker also offers an empty slot. | ADR 0021, 0025; `contracts/presets.md`, PR-9 |
| 59-10 | Without a startup preset the product starts with a TI-59, the Master Library module and no printer (today: printer connected). | ADR 0021 |
| 59-11 | Changing the module, or connecting or disconnecting the PC-100C, power-cycles the machine: the TI-58 and TI-59 lose program and data registers; the TI-58C keeps its constant memory. | `contracts/peripherals.md`, P-1 |
| 59-12 | The TI-58C keeps its constant memory across starts only while no startup preset is set for it; a startup preset cold boots it. A TI-58C built from a preset or a startup preset never writes the constant memory file, so loading an example keeps the user's constant memory for the next TI-58C built from the file (today a load keeps H00 to H03 and the file mirrors whatever runs). | `contracts/capabilities.md`, C-3 as amended 2026-11-13 (user) |
| 59-13 | A second key pressed while another is held no longer releases the first; both reach the key matrix. | `contracts/typing.md`, T-3 |
| 59-14 | Menus and the control bar follow the family structure. Where there is a menu bar (Qt6, the Swift frontend on macOS, the Web frontend's wide layout), Reset, Cold boot (today "Clean"), Load Preset and Settings are menu items and leave the bar; "Clean" with Ctrl or Command held goes. Where there is none (iOS, the Web frontend's portrait layout), the three buttons stay, a More button holds Examples, Cold boot and Help, and the long press for "Clean" goes. The PC-100C is connected with a button on the bar, not in the printer panel. On macOS the Swift frontend's model picker moves from the window toolbar to the bar and Help is new. The Machine menu has Resume. The Web frontend shows a notice as a dialog instead of a line below the calculator. | ADR 0024; LIB-14, C59-8 (user, batch 5 and batch 6 gates) |
| 59-15 | The TI-58C's constant memory is in place before the ROM starts, so the partition and the display format come back at a start as on the real calculator. To be confirmed in phase 6 whether 2.3.0, which restores the registers after the ROM's start-up, showed otherwise. | C59-3 AC-2 (user, batch 5 gate) |
| 59-16 | A damaged constant memory file and a failed write of it are reported with a notice (today: silent). | C59-3 EC-3, EC-4 (user, batch 5 gate) |
| 59-17 | A Reset, a power cycle (a module change, the PC-100C attached or detached) and a Cold boot keep the cue card that is fitted, on every model (today: it is taken away); a fitted magnetic card can still be fed afterwards. The constant memory file remembers the fitted cue card as it is. | user, batch 5, 6 and 7 gates; C59-3 AC-4, AC-11; C59-7 AC-25 |
| 59-18 | While the PC-100C is detached the paper panel shows an empty paper without a name (today: the paper stays in view); the paper is back when the printer is attached again. | LIB-8 AC-8, AC-12, AC-29 (user, batch 6 gate) |
| 59-19 | Traces: one at a time (today the button's and a preset's can run side by side); a trace holds the CPU's instructions and gaps only (today the button's trace also records keys and cards); a trace that cannot be started fails its preset (today: an alert, and the preset goes on); a notice when the size limit ends a preset's trace (today: only the button's). | LIB-10 AC-22 to AC-24 (user, batch 6 gate) |
| 59-20 | Files: a file named at the start, or opened with Open With, is opened as what it is (today: always as a preset); a refusal that was silent is a notice (a file the product cannot open, a card on a model without a reader, a card while one is in the reader); a card the ROM does not take at once stays at the reader until it does; an empty side gives the ROM zeroes, and the ROM ends the read with an error. | LIB-13 AC-1, AC-12, AC-14; C59-7 AC-7 (user, batch 7 gate and after) |
| 59-21 | An ASM overlay runs until a Reset, a Cold boot or Clear: a FREEZE no longer opens the CALCULATOR tab again while the processor is inside the overlay, and FREEZE, STEP and RESUME work on its instructions. | C59-4 AC-18 (user, batch 8 gate) |
| 59-22 | A Reset keeps the partition on the TI-59 and TI-58 (today, as read from the code: the partition goes back to the ROM's default). | C59-1 AC-6 (user, 2026-11-11) |
| 59-23 | A key that a preset or a host key sequence presses is held for 100 ms of emulated time (today: of wall time). At full speed a key therefore no longer keeps the machine running for longer: `Adv` feeds the same lines at every speed (today one press feeds many lines at full speed), and an `Elapsed:` line over a full-speed stretch counts less. | `contracts/typing.md`, T-1; `contracts/presets.md`, PR-10; LIB-5 AC-20 |
| 59-24 | The sides of a magnetic card are 0 and 1 (today 1 and 2), in presets, in the card file and on screen. | user, 2026-11-13; `docs/formats/media.md` §1 |
| 59-25 | The PC-100C's TRACE switch keeps its position when the printer is detached and attached again, as the real switch does (today: off); a preset sets it off unless it says `printer-trace: on` (today a preset without `PRINTER: on` keeps it). | user, 2026-11-13; C59-6 AC-6 |
| 59-26 | Under Examples, `fastmode-sst` is the last of "Programs", not tenth after the printer pictures. | user, 2026-11-13; C59-2 AC-13 |
| 59-27 | A magnetic card carries its own cue card (from `magnetic-cards:` or from its card file), never the preset's `cue-card:`; a card without one shows a plain card titled with its name; a card a preset feeds is fitted after it has passed, in-file cards too. | user, 2026-11-13 (B-6 of `docs/walkthroughs/presets.md`); `docs/formats/cue-card.md` §2, `media.md` §1.4 |
| 59-28 | A keystroke program file (`.keystrokes.yaml`) can be opened or dropped: its program goes into the running calculator without a cold boot. A Solid State ROM module file or the constant memory file is refused with a notice. | user, 2026-11-13; LIB-13 AC-23 |

## Calc-U-1600 (against 0.8.1)

| # | Change | Source |
|---|---|---|
| 1600-1 | Presets with `format-version: 1` are refused with a hint; the format is version 2. Module definitions stay readable; floppy disks are version 2 and those of 0.8.x are refused until upgraded (1600-19). | ADR 0037; `contracts/presets.md`, PR-2 |
| 1600-2 | Settings start at their defaults (INI file). | `contracts/settings.md`, ST-1 |
| 1600-3 | Preset syntax: `- key:` takes several key IDs, `- wait:` needs a unit, the hardware key `plotter:` becomes `printer:`; references are written `{ name: }`, `{ file: }`, `{ folder: }`; a floppy disk is inserted by the step `- floppy:` (sides 0 and 1), a tape by `- tape:`, and `- eject:` empties either; `cut-paper:`, `skip-wait:` and `let-it-finish:` are new; the debugger steps are not available on the Sharp models. | `contracts/presets.md`, PR-5, PR-7, PR-11 |
| 1600-4 | Choosing a module power-cycles the machine (today: a restart like a model switch). The memory is kept through the power cycle; the ROM then finds the changed memory and asks the user to set BASIC up again (`NEW0? :CHECK`), as on the real device and as after today's restart. | `contracts/peripherals.md`, P-1 |
| 1600-5 | A media name with a character a file name cannot hold is refused (today: `/` and `:` silently become `-`). | `contracts/media.md`, MD-3 |
| 1600-6 | An outdated file shows in its picker as a disabled entry with a hint (today: left out silently). | `contracts/media.md`, MD-4 |
| 1600-7 | *Withdrawn 2026-11-13:* a medium a preset names is written in place unless its file is a template, as today (ADR 0019 as amended 2026-11-13). | user, 2026-11-13 |
| 1600-8 | A held host key stays down until it is released, for every key, so the ROM's own auto-repeat works; the PC-1500's fixed key cadence goes: its key readiness was found (first step 15, 2026-11-14). | `contracts/typing.md`, T-2, Q-3; LIB-5 AC-31 |
| 1600-9 | Keys pressed while a preset, a load, a reset or a power cycle runs are dropped (today: held back in Qt6, passed on in the Web frontend). Reset, Cold boot and a model switch stop what runs. | `contracts/typing.md`, T-4; `contracts/frontend.md`, Q-1 as amended |
| 1600-10 | Menus and the control bar follow the family structure: Settings… is in File; Help has a help item; Examples is a menu of its own in the Web frontend; on the PC-1600's bar a printer picker (none, CE-150, CE-1600P) replaces the CE-1600P button and the CE-158 has a button; a notice has no title; a control that cannot be used says why. | ADR 0024; LIB-14 (user, batch 5 gate) |
| 1600-11 | A preset is checked as far as possible before the running machine is given up: a module or a disk that is missing, a host drive folder that does not exist, a ROM image that does not fit, a key that is none and a character without a key refuse the preset and leave the machine alone (today: found after the old machine is gone). A preset opened without its folder is refused when it names a file. | `contracts/presets.md`, I-2; LIB-6 AC-7, AC-52, EC-5 (user, batch 5 gate) |
| 1600-12 | The paper panel is always shown: empty and without a name while no plotter is plugged in. The CE-150 and the CE-1600P each keep their paper until Cut, a preset that names them, or the end of the program: through detaching, a change of ROM, a module change and a model switch, also from a PC-1500 to a PC-1600 (today: the panel is there only with a plotter, and the paper is lost at each of these). | LIB-8 AC-8, AC-12, AC-36 (user, batch 6 gate) |
| 1600-13 | Media: a failed autosave is reported with a notice (today: silent); every change is written when the Web frontend's tab is hidden; a module change leaves the other slot and the disk alone; Name & Save asks before it replaces an instance of that name (today: the name is refused); deleting a saved medium in the Web frontend asks first. | LIB-7 AC-13, AC-14, AC-31, AC-38, AC-40 (user, batch 6 gate) |
| 1600-14 | Traces: the size limit holds for a preset's trace too, and a notice says when it ends a trace (today: a line in the INSPECTOR, for the button's trace only). The run control can pause the machine in both frontends (the harness `pause`, `step`, `resume`; preset debugger steps are not available on the Sharp models); the Machine menu has Resume. "Copied to clipboard" is shown after Copy on the paper. | LIB-10 AC-24, AC-40, AC-43; LIB-14 AC-1; LIB-8 AC-20 (user, batch 6 gate) |
| 1600-15 | Files: a disk file can be dropped and is used where it lies (Web: imported); a module file that is opened is plugged in when it is clear where it goes (one slot, or a module that fits only one), and refused with a notice otherwise; `.rom` is no longer a name of a machine-code file, on a drop or with Open With; a file named at the start of the program is opened (today: passed over); a drop no longer changes the folder a file dialog starts in; a file over 1 MiB and a file the product cannot open are refused with a notice (today: silently). A PC-1500 machine-code load that meets a byte that is not RAM writes nothing (today: the rest, then it fails); an empty file is refused as empty by every loader; each refusal of a loader has one wording. | LIB-13 AC-1, AC-19 to AC-21; C1600-2 AC-10, EC-1 (user, batch 7 gate and after) |
| 1600-16 | A Cold boot also empties a RAM module that has no battery of its own (CE-151, CE-155); a battery-backed module keeps its content (today: Reset All leaves every module as it is). | C1600-1 AC-6 (user, 2026-11-11) |
| 1600-17 | Saving a CE-161 with the write-protect switch set power-cycles the machine, as plugging in a module does (today: nothing follows). | LIB-7 AC-19; LIB-2 AC-32 (user, 2026-11-11) |
| 1600-18 | A cassette tape is a tape definition (`.tape.yaml`) with its WAV: it has a name and a description, can be a template, and gets Name & Save; the picker offers the empty tape and the saved tapes. A WAV of today's tape folder is not listed as a tape until it is wrapped in a definition; a dropped or opened WAV is loaded as a program. | user, 2026-11-13; LIB-7 AC-42 |
| 1600-19 | The sides of a floppy disk are 0 and 1 (today A and B), in presets, in the disk file and on screen; the disk file is version 2, so a disk saved with 0.8.x is refused with the hint until it is upgraded by hand (rename `a:`/`b:` to `0:`/`1:`). | user, 2026-11-13; `docs/formats/media.md` §2 |
| 1600-20 | When a debug session starts, a program started with `after: call` runs only after the client's breakpoints are set (`configurationDone`), not already during `attach`, so a breakpoint near the entry is not missed. | user, 2026-11-13; C1600-3 AC-7 |
| 1600-21 | Only the presets of the bundle file and the files it lists are bundled, not their whole folders: nine examples outside the list no longer start with `?preset=` on the web; the release no longer has `Calc-U-1600-examples.zip`, and the documentation explains how to get every example from the source repository. | user, 2026-11-13; LIB-6 AC-31, C1600-4 AC-17 |
